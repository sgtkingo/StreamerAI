# Encrypted household backups

Household downloads and automatic cloud copies use the same `streamerai-master-pin-household` format. The eight-digit Master PIN is required to open either copy. No printable recovery key is issued. The server keeps the household data key in its encrypted secret vault; each exported file contains a new Argon2id salt and an authenticated AES-256-GCM wrapping of that key. The cloud stores only ciphertext and metadata, never the PIN or plaintext profiles.

A home server must verify the Master PIN once to cache it in its encrypted vault. An online server then creates a backup after account changes and checks for outstanding changes every minute. It reads the cloud revision before writing and refuses to overwrite a revision changed by another server. Settings show whether the last backup is current, pending, saving or needs attention, with the last successful save time. If the cloud is unavailable, the server retries later. Local file export uses the cached PIN and also works without a cloud account.

An owner can restore from a local file or load the current cloud copy into a clean household. The existing PIN is entered to preview the profile names and credential types before confirmation. Import authenticates the entire payload before writing. It rejects configured households, existing credentials and conflicting profile sync IDs; it never merges or overwrites another household. The first-run unused Viewer placeholder can be replaced.

The portable format includes profiles and their preferences, profile PIN verifiers, library membership, watch history, playback positions, feedback, minimum title metadata and allowlisted provider credentials. It excludes media files, caches, server identity, paired devices, local paths, inference configuration, discovery conversations and other server-local data. Use the separate stopped-server full backup for those records. Restored provider credentials are checked when next used.

The cloud checkpoint endpoint is versioned and protected by device authentication and conditional revisions. The 1.8 MB cloud limit is lower than the 16 MiB local file limit. Automatic merging between servers remains unavailable; a changed remote revision is shown as an error rather than overwritten.
