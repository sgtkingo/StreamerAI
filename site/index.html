JEDNODUCHÝ PRINCIP

Jeden server.
Celá domácnost.

01

Server doma

StreamerAI spravuje knihovnu, připojené služby a přehrávání na vašem počítači. Server musí být během používání zapnutý.

02

Klient v prohlížeči

Na dalším zařízení otevřete adresu domácího serveru. Klient nepotřebuje Node ani FFmpeg. Volitelný režim párování vyžaduje schválení správce.

03

Data pod kontrolou

Lokální knihovna funguje bez cloudového účtu. Připojené internetové služby potřebují síť; AI je volitelná.

PRVNÍ INSTALACE

Nejdřív server.
Potom váš večer.

Server připraví instalační průvodce pro Windows nebo podporovaný Linux. Zajistí potřebné komponenty a nabídne Ollamu i lokální model, pokud chybí. Ostatním zařízením stačí webový prohlížeč. Instalační vydání jsou zatím ve vývoji; dostupnost vždy ověřte v Releases.

Otevřít instalační návod ↗
  1. Připravte domácí server.

    Spusťte instalátor na počítači, který bude během používání zapnutý. Průvodce připraví službu, soukromé úložiště a lokální přístup.

  2. Otevřete aplikaci.

    Využijte již nainstalovanou Ollamu a model nebo potvrďte jejich přípravu. Po instalaci se otevře prohlížeč pro vytvoření profilu a připojení vašich služeb. Můžete pokračovat i bez AI.

  3. Připojte další zařízení.

    Před zapnutím LAN přístupu připravte důvěryhodné HTTPS a řízení přístupu podle návodu.
